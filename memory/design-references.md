# Design References — the reference palette

The studio's curated palette of products whose public design stories embody the values — and the anti-references to contrast against. **Agents draw aesthetic examples and lineage from this file** rather than from any one product the studio happens to be building. Cite the *method and what the field learned*, never just the output.

This is a **configurable layer.** Ship the curated default below; `/studio:init` (setup) prompts each user to add their own positive and negative real-world examples so the palette is vivid and personal to their taste. Personal additions live in the consuming project's `.claude/memory/design-references.md` and extend (never silently replace) this default.

Format: Product → Observation → Lesson → Stance.
Stance: Positive / Negative / Mixed / Admire-the-move.

## Counter-References — contrast against these

| Product | Pattern | Why it fails |
|---------|---------|--------------|
| Sonos (2024 app) | A redesign that removed working features | Change for its own sake; the cautionary tale of breaking what worked. |
| Adobe | Feature accretion, subscription hostility, cluttered surfaces | Accumulation without removal; the user pays the complexity cost. |
| Amazon (main app) | Ad-saturated, dark patterns, density without hierarchy | Monetization over the user; noise mistaken for capability. |
| Instagram | Engagement mechanics over the original idea | Lost the restraint that made it good; optimized for frequency, not value. |
| old iTunes | One app made to do everything | The canonical bloat story — scope with no organizing logic. |
| LinkedIn | Notification spam, manufactured engagement | Manufactured urgency erodes trust for short-term metrics. |
| Booking · Expedia | "1 left!" urgency, manipulative defaults | Manufactured scarcity; defaults that serve the seller, not the user. |
| Jira | Configuration as a substitute for opinion | When everything is configurable, nothing is designed. |
| Google messaging (Allo→Duo→Chat) | Strategic incoherence over time | A product line with no through-line; users pay for the indecision. |
| Most cookie-wall news sites | Interruption as a business model | The interface works against the person reading it. |
