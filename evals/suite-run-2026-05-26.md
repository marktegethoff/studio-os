## Failures (ranked by severity)

### 1. `cd` — gate agent — Eval 2 (Non-activation)
**Criterion failed:** "Response redirects to the appropriate discipline (Engineer)"
**Gap:** Agent defines what CD activates on but has no instruction for out-of-scope (engineering/implementation) prompts. No-code rule covers code authorship only, not answering implementation questions.
**Fix:** Add one line to Rules: "If the prompt is an engineering or implementation question, name the Engineer and do not deliver a verdict."

### 2. `accessibility` — no eval scenarios
**Gap:** Listed in surface-agents.eval.md but no eval scenario exists. Violates the coverage rule.
**Fix:** Add at least 1 eval scenario to `surface-agents.eval.md`.

### 3. `design-validator` — no eval scenarios
**Gap:** Same as accessibility. Coverage rule violation.
**Fix:** Add at least 1 eval scenario to `surface-agents.eval.md`.

### 4. `historian` — Eval 4 (Scope Discipline), Criterion 3
**Criterion failed:** "Relevant adjacent material offered as a separate note, not folded in"
**Gap:** Agent defines scope as a judgment call based on analogy ("adjacent enough to be genuinely informative") but has no mechanism for honoring user-stated exclusions. A user who says "just X, not Y" is not reliably served.
**Fix:** Add rule: "When the user names what is out of scope, honor it. Do not include excluded material under the guise of context."
**Secondary gaps (unguarded anti-patterns):** training-knowledge boundary acknowledgment; blanket refusal prevention; absence-of-evidence ≠ evidence-of-failure.

### 5. `surveyor` — Eval 8 (Field signal vs. position), Criteria 1–2
**Criteria failed:** Source citation not required in output; competitive intelligence filtering scoped to design principles only, not strategic positions/invariants.
**Note:** Evaluator flagged a possible scope mismatch — the Surveyor is a design-research sweep agent; the eval may be testing it as a competitive intelligence agent. Resolve: either add competitive position-filtering to the Surveyor, or re-scope Eval 8 to the Strategist.
**Fix (regardless of scope decision):** Add "each finding must include a source" to the output format.

### 6. `typesetter` ◐ — Eval 4 (Structural role before values), Criterion 4
**Criterion partial:** "Scale values use named tokens, not raw pt values"
**Gap:** Output Structure template uses `[Xpt]` notation throughout — actively models raw pt values. No Named Ban equivalent of Specifier's Raw Value Slip.
**Fix:** Add Named Ban "Raw Value Slip" for type scale; update output template to model token syntax.

### 7. `systematist` ◐ — Eval 7 (Drift over preference), Criterion 4
**Criterion partial:** "Recommends consolidation to one component + one token source, not a fourth"
**Note:** This is a criterion-agent mismatch, not an agent defect. The Systematist is deliberately non-prescriptive (governance role). The eval criterion expects directive language.
**Fix:** Update eval criterion 4 to match the agent's actual governance stance: "Identifies that the count must reduce and flags the decision — does not add a fourth."
