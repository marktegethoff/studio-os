D

States

structural delta · trigger
  1. D1
    scanningAll clients show expanded. The full open-work list is visible. "Close week →" shows dim because no action has happened yet. This is the entry state every week. It is the state in A.
    entry state
  2. D2
    Item closedTap an open item. [·] flips to [✓]. The row dims. The client open count drops by one. The row stays in place until the user closes the week. The user sees what got done, not only what remains.
    ↓ tap an open item
  3. D3
    Client collapsedTap a client header. Its item rows collapse. The header and the open count stay. This clears noise from clients already reviewed. "Close week →" activates only when all items across all clients are resolved or rolled.
    ↓ tap a client header
  4. D4
    Roll unfinishedTap "Close week →" while any [·] item remains. A sheet lists every open item with a binary choice: roll to next week, or mark dropped. The decision waits until the user finishes the scan. It does not interrupt the review.
    ↓ Close week with open items
  5. D5
    Week closedAll items are resolved or rolled. "Close week →" becomes "Week closed ✓". The week label advances to the next ISO week. The screen moves to the empty scanning state of the new week.
    ↓ all items resolved or rolled
D1 is drawn in A. Add a frame only when a transition changes the layout. Write every other state as one line.
