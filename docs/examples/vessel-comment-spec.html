Vessel Comment Thread.

Inline comment annotation anchored to text selection in a long-form document. Supports threaded replies, read/unread states, and resolution. Every state and token named — the handoff that removes guessing.

State Preview

States

StateTriggerAppearance (named tokens only)
Anchored / Unread Collaborator posts comment; author has not opened thread Left border: --amber (#D4A844); background: --bg-2; amber dot indicator position: absolute, top-right corner, font-size 0.5rem
Anchored / Read Author has opened and read the thread; thread is closed Left border: --border; background: --bg-2; text color: --text-2; dot indicator removed
Expanded Author or collaborator clicks/taps the comment anchor to open the thread panel Left border: --text-1 (3px); background: --bg-1; full border: --border; padding increased to 1rem; text color: --text-1
Composing Reply Author focuses the reply input field within an expanded thread Left border: --amber (3px); background: --bg-1; full border: --border; reply input field border: --amber; send button: background --amber, text #fff, enabled
Resolved / Collapsed Author or moderator marks comment thread as resolved and collapses it Left border: --border; background: --bg-3; text color: --text-3; text-decoration: line-through; opacity: 0.65; anchor text remains visible but muted
Orphaned The text this comment anchors to is deleted from the document Left border: #D4A844 (3px); full border: #D4A844 (1px solid); background: --bg-1; warning indicator: ⚠ prefix, color #D4A844; label text: "anchor lost"; border-radius: 4px

Unspecified states: animation duration for thread slide-in (request from engineering). Accessibility labels per state are defined in Accessibility section below.

Accessibility

ARIA Label aria-label="[Author]: [first 20 chars of comment]" — e.g., "Sarah: You might want to reconsider this…"
Role role="note" — indicates an annotation/comment structure
Keyboard Navigation Tab moves focus between comment anchors in document order. Enter or Space opens expanded thread. Tab within thread moves focus to reply input, then send button. Escape closes expanded thread, returns focus to anchor.
Unread Indicator aria-live="polite" on unread dot; announces "[Author] has posted a reply" when new comment added
Touch Target Comment anchor ≥ 44pt height; reply send button ≥ 44×44pt
Contrast Text on --bg-2: WCAG AA confirmed. Resolved state (--text-3 on --bg-3): WCAG AA for muted/secondary content. Unread amber indicator (--amber): WCAG AA on both light and dark backgrounds.

Gaps resolve before build

Thread slide-in animation duration Engineering decides
Expanded state does not specify transition/animation timing. Design shows instant appearance. Specify duration (e.g., 0.2s) or accept snap-open behavior. Engineering will guess otherwise.
Orphan warning color token Design System decides
Orphaned state uses #D4A844 amber for warning indicator, but no design system token exists for "warning" or "orphan-indicator." Define as token or accept hardcoded value.
Resolved thread interaction Design decides
Resolved state shows anchor as muted. Specify whether clicking a resolved anchor should expand the thread (read-only) or remain permanently collapsed. Current spec: behavior undefined. Spec it or acknowledge the risk.
Dark mode tokens Design System decides
All token references assume light mode. Define dark mode variants for --bg-1, --bg-2, --bg-3, --text-1, --text-2, --text-3, and --amber in :root[data-theme="dark"] or @media (prefers-color-scheme: dark).
