Vessel Comment Thread

An inline comment anchored to a text selection in a long-form document. It supports threaded replies, read and unread states, and resolution. This sheet names every state and token, so engineering does not guess.

States

trigger · delta from C1
  1. C1
    Anchored · unreadTrigger A collaborator posts a comment. The author has not opened the thread. Appearance As drawn in A1 to A5.
    ✓ Specified
  2. C2
    Anchored · readTrigger The author reads the thread and closes it. Delta Left border --border. Text --text-2. Remove the dot.
    ✓ Specified
  3. C3
    ExpandedTrigger The author or a collaborator clicks or taps the anchor. The thread panel opens. Delta Left border --text-1, 3 px. Background --bg-1. Full border --border. Padding 1 rem. Text --text-1.
    ✓ Specified
  4. C4
    Composing replyTrigger The author focuses the reply input in an expanded thread. Delta Background --bg-1. Full border --border. Reply input border --amber. Send button background --amber, text #fff, enabled.
    ✓ Specified
  5. C5
    Resolved · collapsedTrigger The author or a moderator marks the thread resolved and collapses it. Delta Left border --border. Background --bg-3. Text --text-3. Line-through. Opacity 0.65. Keep the anchor text visible, muted.
    ✓ Specified
  6. C6
    OrphanedTrigger The anchored text is deleted from the document. Delta Left border #D4A844, 3 px. Full border 1 px solid #D4A844. Background --bg-1. Warning prefix ⚠ in #D4A844. Label per B4.
    ✓ Specified
  7. C7
    Thread slide-in durationThe expanded state has no transition timing. Design shows an instant open. Specify a duration, such as 0.2 s, or accept snap-open. Engineering will guess otherwise.
    ✕ Gap
    Engineering decides
  8. C8
    Orphan warning color tokenThe orphaned state uses #D4A844 for the warning. No token exists for a warning or an orphan indicator. Define a token or accept a hardcoded value. See D10.
    ✕ Gap
    Design System decides
  9. C9
    Resolved thread interactionSpecify whether a click on a resolved anchor opens the thread read-only or leaves it collapsed. The current behavior is undefined. Specify it, or accept the risk.
    ✕ Gap
    Design decides
  10. C10
    Dark mode tokensEvery token in D assumes light mode. Define dark variants for --bg-1, --bg-2, --bg-3, --text-1, --text-2, --text-3 and --amber. Use :root[data-theme="dark"] or @media (prefers-color-scheme: dark).
    ✕ Gap
    Design System decides
Write each state as its delta from C1. Keep each unlisted property at its default. Resolve every gap before build.
