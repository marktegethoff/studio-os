B

Layer 1 · Canonical heuristics

Nielsen H1–H10 · always applied
  1. B1
    The mood tag ("Anxious", "Restless", "Calm") cannot be corrected or dismissed once generated Violates H3 · User control and freedom · AI-UX correction · AI attribution Evidence An AI-assigned emotional label sits on the user's morning with no path to disagree. Wrong tags build a silent record. Trust erodes at each encounter. Fix Make the tag tappable. One tap reveals alternatives and a dismiss action. Use no modal. Add no chrome to the resting state. Do not add a persistent edit affordance. Trade A user who misses the tap keeps a wrong tag (E1).
    P0
  2. B2
    The reflect prompt is AI-generated from the previous night's memo, but it reads as a static, hand-authored app prompt Violates H4 · Consistency and standards · AI-UX transparency Evidence The prompt has no origin indicator. Users cannot tell whether Drift's team wrote the question or the app composed it this morning. Fix Apply the AI register from D1: one mono label, no decoration. Every AI-authored surface reads as AI-authored at a glance. If the system has no AI register, define it once. Apply it to the summary and to this prompt in the same pass.
    P1
  3. B3
    Nothing shows whether the mood tag came from the bedtime memo, the morning memo, or both Violates H1 · Visibility of system status · AI-UX model transparency Evidence The model's input scope is invisible. Users cannot reason about why the tag is what it is. Fix When the user taps the tag (B1), reveal the source beside the alternatives: "from last night", "from this morning", or "from both". The disclosure rides on the B1 fix. It needs no new surface.
    P2
Layer 1 holds three findings.
C

Layer 2 · Platform contract

HIG · iOS surfaces
  1. C1
    The voice memo play button measures 36 × 36 pt. It is the primary action and the gesture the whole surface serves Violates HIG · Touch target · WCAG 2.5.5 Evidence The primary control sits below the 44 pt minimum.
    Target size36 · min 44 pt
    060
    Fix Raise the target to 44 × 44 pt. Keep the visual mark at its current size. Expand the hit region. The composition does not change.
    P1
Layer 2 holds one finding.
D

Layer 3 · AI interaction

AI behavior shows
  1. D1
    The AI summary uses the same type, weight, and color as the user's own transcribed words Violates AI-UX · Attribution · H4 · Consistency and standards Evidence In feedback sessions users call the AI summary "what I said". They cannot tell their voice from the model's paraphrase. Fix Demote the summary below the user's content. Set it in the system's AI register: lighter weight, secondary color, mono label "summary". The user's words are the principal. The summary is a quiet annotation. Do not add an AI badge to the transcript. Fix the summary, not the source.
    P0
Layer 3 applies because AI behavior shows. The product names no AI principle.
